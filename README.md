# Sarpanch Exit Poll

Mobile-first Hindi website for ग्राम पंचायत / सरपंच चुनाव exit-poll style survey results.

## Stack
- Zero-dependency static HTML/CSS/JavaScript
- Deployable directly on Vercel
- No backend required for the initial demo

## Important
The sample results in `index.html` are demo data. Replace them with verified survey data before publishing.
